# Network+ (N10-009) Study Notes

My personal study notes for the CompTIA Network+ N10-009 exam. I'm working through the material section by section and writing everything in plain English, with analogies, real-world examples and exam tips.

> These are my own notes and summaries. They are not official CompTIA material and don't reproduce any course content.

## How each guide is laid out

1. Simple explanation, built from the basics
2. At least one analogy per concept
3. Where you'd see it on a real network or in a dev environment
4. What CompTIA is likely to test, plus common traps
5. A **Key Terms** section at the end (definition, analogy, example, exam tip)
